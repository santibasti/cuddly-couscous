# Choi Narciso — portfolio site

Static site (HTML/CSS/vanilla JS, no build). Run `python3 -m http.server` in this folder and open http://localhost:8000.

**Placeholder images:** everything in `img/` is a low-res crop from Instagram screenshots, for layout preview only.
Replace with the photographer's full-resolution originals (same filenames, or edit the arrays at the top of `main.js`).
Aim for ~2400px on the long edge, JPEG/WebP, ~300 KB each.

Copy (about text, "In print" list, statement) is draft: confirm with the photographer.

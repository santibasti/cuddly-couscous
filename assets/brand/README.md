# Brand assets

Place the official logo here as **`cattle-creek-logo.png`** (SVG also works if you
change `LOGO_SRC` in `js/brand.js`).

The app displays the file exactly as supplied: it is never redrawn, recolored,
or distorted (only scaled proportionally with `object-fit: contain`). It is used
on the login screen, sidebar, dashboard header, receipt preview, and reports.

Until the file is present, a plain text wordmark ("Cattle Creek Country Club")
is shown instead.
